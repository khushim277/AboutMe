# AboutMe 🌤️🌙

A responsive personal portfolio website built using HTML, CSS and JavaScript!

This was one of my first personal web development projects and was created to practise frontend development while building a website that introduces who I am, my technical skills and my interests.

## Features

* ☀️ **Day and Night Mode**: interactive theme toggle built with JavaScript
* 📱 **Responsive Design**: adapts to desktop and mobile screen sizes
* 🧭 **Smooth Navigation**: navigation between different sections of the page
* 👩‍💻 **About Me**: introduction and background
* 💻 **Skills Section**: displays my current technical skills
* 🎸 **Hobbies Section**: a little more about my interests outside of software
* 📩 **Contact Section**: links to email and LinkedIn
* ✨ Interactive cards and hover effects

## Technologies Used

* **HTML5** - page structure and content
* **CSS** - styling, responsive layouts, themes and animations
* **JavaScript** - interactive day/night theme functionality

## What I Learned

Building this project helped me strengthen my understanding of:
* Structuring a webpage using semantic HTML
* Creating responsive layouts with CSS
* Using CSS variables and media queries
* Manipulating HTML attributes using JavaScript
* Implementing interactive UI features
* Designing reusable visual components
* Using Git and GitHub for version control
